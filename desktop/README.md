# NeriPlayer Desktop（音理音理 · Linux 原生版）

把 Android 应用 [NeriPlayer](https://github.com/cwuom/NeriPlayer) 重写为**不依赖 Android 运行环境**的
Linux 原生桌面应用：Kotlin + Compose Desktop（JVM / Skia），使用 JDK 17 运行，打包为 `.deb`。

## 功能对照

| 原 Android 功能 | 桌面版实现 |
| --- | --- |
| 首页（继续播放 / 为你推荐 / 热歌榜 / 推荐新歌 / 私人雷达 / 热门榜单） | ✅ 已实现（网易云公开接口 + 本地回退栏目） |
| 探索（多源搜索、搜索历史、热门搜索、风格标签、推荐歌单） | ✅ 网易云（歌曲/歌单/歌手/专辑）、哔哩哔哩（视频）、本地媒体库 |
| 媒体库（本地/收藏/网易云/哔哩哔哩/QQ 音乐） | ✅ 本地歌曲·歌手·专辑·歌单 + 收藏 + 在线音源浏览（QQ 音乐为占位） |
| 播放页（封面、进度、随机/循环、队列、定时器、音量、音效） | ✅ 已实现，宽窗口下左侧封面 + 右侧歌词双栏 |

| 播放队列（拖动排序、移除、跳转） | ✅ 上/下移 + 移除 + 点击播放 |
| 歌单（新建、收藏、增删歌曲） | ✅ 含系统歌单「我喜欢的音乐」 |

## 环境要求

- JDK 17 或更高（打包产物已内置 jlink 运行时，终端用户无需 JDK）
- 运行期依赖：`ffmpeg` / `ffprobe`（推荐）。缺失时自动使用 Java Sound 回退引擎，
  仅支持 mp3 / flac / ogg / wav / aiff，且没有倍速、变调、响度与均衡器
- 构建期依赖：Gradle 8.9+（仓库内含 wrapper），网络可访问 Maven Central

## 构建与运行

```bash
./gradlew run            # 直接运行
./gradlew selfTest       # 核心自检：解码 / 播放 / 跳转 / 变速 / 歌词解析 / 在线接口
./gradlew packageDeb     # 生成 build/compose/binaries/main/deb/neriplayer_1.0.1-1_amd64.deb
```

安装与启动：

```bash
sudo dpkg -i neriplayer_1.0.1-1_amd64.deb
neriplayer            # 或从应用菜单启动「NeriPlayer」
```

首次启动会显示使用须知；在「设置 → 媒体库」中添加音乐文件夹后点击扫描即可建立本地库。

## 登录网易云与哔哩哔哩

两者都在应用内扫码登录，不需要输入密码：

1. 打开「设置 → 账号」；
2. 在「网易云」或「哔哩哔哩」行点击 **扫码登录**；
3. 用对应的手机客户端扫描弹窗里的二维码（网易云音乐用「扫一扫」，哔哩哔哩用右上角「+ → 扫一扫」）；
4. 手机端确认后，弹窗会显示账号昵称并自动完成登录，之后可随时在同一位置「退出登录」。

- 二维码有效期约 2 分钟，过期后点击「刷新二维码」重新获取。
- 登录后：媒体库「网易云」分栏会出现「我的歌单」，「哔哩哔哩」分栏会出现「我的收藏夹」，
  在线播放也会使用账号可用的更高音质（在设置 → 播放 → 默认音质中选择）。
- 登录凭据（Cookie）只保存在本机 `~/.config/NeriPlayer/accounts.json`，文件权限 600，不会上传到任何第三方。
- 未登录时依然可以使用公开搜索、推荐、歌词与试听音质，只是看不到个人歌单与收藏夹。

## GitHub 同步

与原 Android 端使用**同一套同步协议**：数据写在你自己的 GitHub 仓库根目录，
普通通道为 `backup.json`，省流通道为 `backup-raw.bin`（GZIP + Protobuf）。
因此在手机上同步过的歌单、收藏、最近播放与播放统计，桌面端可以直接拉取，反之亦然。

配置步骤（设置 → 同步）：

1. 在 GitHub 生成一个带 `repo` 权限的 Token（建议 fine-grained 且只授权给同步仓库），填入并点「验证 Token」；
2. 点「创建私有仓库」（自动建 `neriplayer-sync` 之类的私有仓库）或「选择现有仓库」；
3. 开启「自动同步」后，歌单 / 收藏 / 最近播放 / 统计发生变化会在 15 秒内自动同步；也可随时点「立即同步」。

实现要点：

- 拉取远端 → 按策略合并 → 写回本地 → 用 Git 数据接口提交（带读取时的 HEAD，非快进会被拒绝，冲突自动重试一次）
- 合并策略：歌单按修改时间取新、歌曲取并集并尊重删除墓碑；最近播放按歌曲身份去重取最新；
  播放统计按身份 + 日期分桶取 `max`（避免两端相加造成重复计数）
- 同一首歌的身份规则与手机端一致（`id|album|mediaUri`），本地文件以 `file://` 路径表达
- Token 保存在 `~/.config/NeriPlayer/sync.json`（权限 600），不写入设置文件

## 悬浮歌词

Linux 上对应手机端的悬浮窗：一个**无边框、置顶、可拖动**的歌词条，播放时实时显示当前歌词（含翻译）。

- 开启方式：设置 → 悬浮歌词（或播放页工具栏的悬浮歌词按钮，快捷键 `Ctrl+L`）
- 位置：直接用鼠标拖动歌词条即可，位置按**屏幕比例**保存，换分辨率或多屏也不会跑出屏幕
- 鼠标悬停歌词条会浮出四个按钮：上一首 / 播放暂停 / 下一首 / 关闭
- 样式项与手机端一致：歌词颜色（十色）、渲染方式（阴影 / 描边）及颜色与宽度或模糊、
  字号、主歌词与翻译不透明度、背景颜色与不透明度、最大宽度、对齐方式、显示翻译、切换淡入
- 「应用内隐藏」开启后，主窗口获得焦点时自动隐藏，避免遮挡页面；「锁定位置」可防止误拖动

> 透明背景需要系统启用窗口合成器（GNOME / KDE / XFCE 默认开启）；未启用时会退化为不透明底色。

## 相对 1.2.0 的修复（1.2.1）

- **悬浮歌词拖动异常**：原实现用 Compose 的「窗口内坐标增量」累加移动窗口，而窗口本身正在移动，
  两者互相抵消，表现为越拖越慢、抖动、跟不上鼠标。现改为**抓取点跟随**：
  窗口目标位置 = 指针屏幕位置 − 抓取偏移，窗口与鼠标相对位置恒定，拖动精确平滑；
  同时拖动中不再被设置回写覆盖（避免回弹），拖出屏幕会被夹回屏幕内。
- **歌单只显示 10 首**：网易云歌单详情接口只返回前若干首（热歌榜声明 200 首仅回 10 首），
  完整列表在 `trackIds` 中。现按 `trackIds` 顺序用歌曲详情接口分批（200 首/次）补齐，
  歌单详情页会显示完整曲目；首页仍限制抓取数量以免浪费流量。

## 数据目录（XDG）

| 路径 | 内容 |
| --- | --- |
| `~/.config/NeriPlayer/settings.json` | 设置、主题、队列与进度快照 |
| `~/.local/share/NeriPlayer/library.json` | 本地媒体库索引 |
| `~/.local/share/NeriPlayer/playlists.json` | 歌单与「我喜欢的音乐」 |
| `~/.local/share/NeriPlayer/history.json` | 最近播放 |
| `~/.local/share/NeriPlayer/stats.json` | 播放统计 |
| `~/.cache/NeriPlayer/artwork`、`covers` | 内嵌封面提取与在线封面缓存 |
